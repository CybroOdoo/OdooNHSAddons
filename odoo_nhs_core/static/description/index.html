Frequently Asked Questions

Do I need to install the NHS modules one by one?

No. Installing NHS Backoffice Management Core automatically installs all 13 NHS modules and their Odoo dependencies (Discuss, Contacts, Portal and Hierarchy View).

What does the NHS Backoffice Administrator group do?

It is a single umbrella group that implies the top access level of every NHS module — for example Trust Administrator, Quality Lead, DSPT Manager, Workforce Manager and Estate Manager. Assign it to a user to give full management access across the suite. Lower-level roles are still assigned per module as usual.

Can I uninstall a single module later?

Each NHS module is still an independent application. Uninstalling one will also uninstall this bundle (because it depends on every module), but the remaining NHS modules stay installed.

Does the bundle add new menus or data models?

No. The core module is a pure bundle — it adds only the installer dependencies and the administrator group. Each module keeps its own app menu, settings and reports.
