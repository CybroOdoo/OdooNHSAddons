NHS Recruitment Pipeline
========================
Vacancy-to-hire recruitment for the NHS — vacancy approval against funded posts, adverts, portal applications, shortlisting, interviews, offers and the NHS Employment Check Standards, with onboarding into the establishment.

Installation
============
- Install the module from the Apps menu.

Configuration
=============
- No additional configuration is required.
